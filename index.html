    03 / projects

    Things I've built

    PROJECT 01

    CAN-Driven Vehicle Monitoring and Driver Assistance System

    A multi-node CAN network where LPC2129 boards share fuel level, vehicle mode, indicator commands and reverse-alert status over one two-wire bus.

    • Built and tested a multi-node CAN vehicle monitoring system using LPC2129 nodes and MCP2551 transceivers.
    • Implemented CAN communication for fuel percentage, vehicle mode, indicator commands and reverse-alert status.
    • Interfaced ADC, external interrupts, LCD, HC-SR05 ultrasonic sensor, LEDs and buzzer for monitoring and driver-assistance functions.
    • Debugged CAN communication between multiple nodes using Keil µVision and Flash Magic.
    • LPC2129
    • Embedded C
    • CAN
    • MCP2551
    • ADC
    • Interrupts
    • Keil µVision

    PROJECT 02 · B.TECH PROJECT

    IoT-Based Energy Monitoring System

    An ESP32 energy monitor that reads electrical parameters from a PZEM-004T meter and publishes them to a live ThingSpeak dashboard.

    • Built an ESP32-based energy monitoring system to measure voltage, current, power and energy consumption using the PZEM-004T meter.
    • Acquired real-time electrical parameters from the energy meter over UART.
    • Created a ThingSpeak dashboard for live data visualization and energy-usage trend analysis.
    • Performed basic analysis to identify abnormal power-consumption patterns.
    • ESP32
    • PZEM-004T
    • UART
    • MQTT
    • ThingSpeak
    • Embedded C

    PROJECT 03

    Mini C Preprocessor

    A simplified C preprocessor written in C: it strips comments, expands macros, follows user headers recursively and writes the preprocessed .i file.

    • Built a simplified C preprocessor supporting //, /* */, #define and user-header #include.
    • Implemented macro storage and replacement using structures, string handling and character parsing.
    • Added recursive header processing with shared macro definitions and generated preprocessed .i output.
    • Tested comment removal, macro expansion, string handling and header inclusion.
    • C
    • File handling
    • Data structures

    PROJECT 04

    ARM7 Peripheral Interfacing Mini Project

    Register-level Embedded C for the core peripherals of an LPC2148 ARM7 microcontroller, tested in Keil simulation.

    • Wrote embedded C programs for LPC2148 peripherals including GPIO, ADC, external interrupts and RTC.
    • Configured peripherals at register level and tested using Keil-based simulation.
